TPS 2: 2D Arrays with Malloc

1. Line #8 (typically: int **arr = malloc(n * sizeof(int*));) allocates an array of pointers. Each element in this array will eventually hold the address of a "row" (a 1D array of integers).

2. We access the i-th value of the array of pointers using pointer notation: *(arr + i).

3. Allocation and Initialization (Pointer Notation):
   for(int i = 0; i < n; i++) {
       *(arr + i) = (int*)malloc(n * sizeof(int));
       for(int j = 0; j < n; j++) {
           *(*(arr + i) + j) = 0; 
       }
   }

4. We must pass the size 'n' because in C, a pointer to a pointer (**arr) does not inherently "know" how many rows or columns it points to. To avoid segmentation faults and to know when to stop the loops, the dimensions must be provided.

5. printArray logic (Pointer Notation):
   void printArray(int **arr, int n) {
       for(int i = 0; i < n; i++) {
           for(int j = 0; j < n; j++) {
               printf("%d ", *(*(arr + i) + j));
           }
           printf("\n");
       }
   }

6. Diagonal Matrix Logic:
   for(int i = 0; i < n; i++) {
       *(*(arr + i) + i) = (i + 1);
   }

7. [Verified]: Calling printArray(arr, n) successfully displays the identity-style matrix with 1, 2, 3... on the diagonal.
